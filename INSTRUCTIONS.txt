HOW TO APPLY:

Easiest: GitHub Web Editor
1. Go to each file path on GitHub
2. Click pencil, select all, delete, paste new content, commit
3. Vercel auto-deploys each commit

For package.json: after updating, Vercel runs 'npm install' automatically.

For file upload: create the 'src/components/' directory first if it doesn't exist.


OPTIONAL: Web Search
- Works without any API key (Wikipedia fallback)
- For full web search, add TAVILY_API_KEY to Vercel env vars
- Free at tavily.com (1000 searches/month)

- Uses Piston API (free, no key needed)
